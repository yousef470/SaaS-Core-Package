Package Structure

After unzipping the package, you will find the following folders:


/SaaS-Core/
├── /assets/         # Images, Icons, and Fonts
├── /css/            # Compiled CSS files
├── /js/             # Main Logic & Components
├── /scss/           # Source Sass Files (Developer Ready)
├── index.html       # Landing Page
├── dashboard.html   # Main Dashboard
└── documentation/   # This documentation file

RTL Support

SaaS-Core is fully optimized for RTL languages like Arabic. To enable RTL, simply add the dir="rtl" attribute to the <html> tag:

<html lang="ar" dir="rtl">
Note: Our CSS automatically detects the direction and flips the layout using logical properties.
