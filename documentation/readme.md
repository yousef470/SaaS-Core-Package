# 🚀 SaaS-Core: Premium Admin Dashboard & UI Kit

SaaS-Core is a high-performance, modern, and fully responsive boilerplate designed for developers and entrepreneurs. It features a sleek "Glassmorphism" aesthetic and is built to be easily customizable without the overhead of heavy frameworks.

## ✨ Key Features
*   **Pure Vanilla JS:** Zero dependencies on heavy frameworks, ensuring lightning-fast performance.
*   **Modern UI/UX:** Features Bento Grids, Glassmorphism effects, and smooth transitions.
*   **Dual Mode & RTL:** Full support for Dark/Light modes and Native Arabic (RTL) support.
*   **Interactive Analytics:** Pre-configured charts (Chart.js) to visualize revenue and user growth.
*   **Ready-to-Use Pages:** Includes Landing Page, Dashboard, Auth (Login/Register), and Profile Settings.

## 🛠 Tech Stack
*   **Styling:** Tailwind CSS & Sass (SCSS).
*   **Logic:** Vanilla JavaScript (ES6+).
*   **Charts:** Chart.js.
*   **Deployment:** Netlify Ready.
