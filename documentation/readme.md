# 🚀 SaaS-Core — Premium SaaS Dashboard & Admin UI Kit

SaaS-Core is a modern, responsive, and high-performance SaaS dashboard template crafted for startups, developers, agencies, and entrepreneurs.

Built with clean Vanilla JavaScript and SCSS architecture, SaaS-Core delivers a premium user experience with elegant Glassmorphism UI, Bento layouts, RTL support, dark mode, and advanced dashboard interactions — all without relying on heavy frontend frameworks.

---

## 🎨 Modern Premium UI
- Glassmorphism design system
